# Healthcare Data Analytics Project

## 1. Project Overview
This project analyses synthetic hospital management data to understand hospital operations, patient visits, laboratory performance, admissions and revenue.

## 2. Project Objective
- Monitor hospital performance using executive KPIs.
- Analyse patient visits by department and month.
- Evaluate laboratory turnaround time and abnormal test rates.
- Compare hospital branch revenue.
- Analyse admissions and average length of stay.

## 3. Dataset
The dataset is synthetic and created for educational and portfolio purposes. It does not represent actual patients or hospital transactions.

The project uses the following tables:
- Visits
- Patients
- Doctors
- Billing
- Lab_Tests
- Admissions
- Pharmacy

## 4. Tools Used
- MySQL – Data storage and SQL analysis.
- Power BI – Dashboard development and visualisation.
- DAX – KPI calculations and time-based analysis.
- Chat GPT & Claude - To Prepare dummy data set.
   
## 5. Dashboard KPIs
- Total Visits
- Unique Patients
- Total Revenue
- Revenue per Visit
- Total Lab Tests
- Average Lab Turnaround Time
- Abnormal Test Percentage
- Total Admissions
- Average Length of Stay

## 6. Disclaimer
All data is synthetic. This project is for learning, demonstration and portfolio purposes only.
